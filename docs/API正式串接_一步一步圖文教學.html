API 正式串接｜新手一步一步操作

本頁只列出需要在外部平台手動完成的操作。網站檔案已經串好，不需要逐頁修改。

1. Apps Script

  1. 開啟 Apps Script 專案。
  2. 將網站壓縮包內 apps-script/Code.gs 的內容完整貼到 Apps Script。
  3. 左側齒輪「專案設定」→「指令碼屬性」。
  4. 新增 ORDER_SHEET_ID、PRICE_SHEET_ID、LINE_ADMIN_IDS、LINE_CHANNEL_ACCESS_TOKEN。LINE 群組通知可選填 LINE_GROUP_IDS。
  5. 右上角「部署」→「管理部署作業」→「編輯」→ 版本選「新版本」。
  6. 執行身分選「我」，存取權限選「任何人」，按「部署」。
  7. 開啟 API 健康檢查，確認顯示 ultimate-final-v8，而且 properties 裡的四項狀態都是 true。
  8. 如果 Google 顯示新的 /exec 網址，只需替換 assets/js/config.js 裡的 APPS_SCRIPT_URL，不要逐頁修改 HTML。

2. Firebase

  1. Firebase Console → Authentication → Sign-in method。
  2. 啟用 Email/Password 與 Google。
  3. Authentication → Settings → Authorized domains。
  4. 加入 xuanxiangtravel.com、xuanxiang-vip-f44.pages.dev、localhost。
  5. 本專案使用命名 Firestore 資料庫 xuanxiangtravel，不要發布到不存在的 (default) 資料庫。
  6. 終端機進入網站資料夾，執行 bash tools/deploy_firebase_rules.sh。若尚未登入，先執行 firebase login。
  7. Firebase Analytics 已由網站自動初始化，不需要逐頁貼上 Firebase 範例程式。

3. Cloudflare Pages

  1. 第一次在終端機執行 npm_config_cache=/tmp/xuanxiang-npm-cache npx --yes wrangler@latest login，並在瀏覽器完成 Cloudflare 授權。
  2. 回到網站資料夾執行 bash tools/deploy_cloudflare_pages.sh。腳本會自動建立 ZIP 並只上傳前端檔案。
  3. 部署後用手機開啟首頁，測試選單、價目表、登入與預約。
  4. 終端機執行 python3 tools/check_live_deployment.py，看到線上驗收全部通過才算完成。
